# Playtest record — Trancefall v1.0.0 (2026-10-30)

Automated playtest of record for the sandbox build (seahawk pass on
primo is the scheduled follow-up, see BREAKAGE-LOG).

## Method

- `node tools/playtest.mjs`: the shipped wasm core in demo mode plays
  each level from `start_level` to a terminal screen. Pass = victory.
- `node tools/settings-check.mjs`: settings bridge round-trip; settings
  reachable from boot without progression.
- `node tools/perf.mjs`: step budget.
- `zig test src/main.zig`: 12 tests, validation + adversarial split.
- D-221 visual spot check: frames extracted from the final preview MP4s
  at viewing size and inspected — SHOULD: dark plum room, centred
  abstract portrait whose posture/expression read at a glance, weather
  visibly coupled to depth, legible HUD. Found one FAIL (preview text
  rendered vertically mirrored — shared rasteriser font rows), fixed,
  re-captured, re-inspected PASS.

## Results

- Level 3 — Trandeep: VICTORY, 2896 steps, depth 0.99.
